# 기업 법무 실무 조치 평가

## 평가 목적

복수 쟁점 답변이 획일적인 안내 대신 쟁점별로 구체적인 후속 조치를 제시하고,
각 조치가 검색된 규칙과 원문 문서에 연결되는지 평가한다.
