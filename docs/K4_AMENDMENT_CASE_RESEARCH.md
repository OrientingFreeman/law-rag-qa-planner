# K4 실제 개정 사례 탐색 결과

## 1. 탐색 목적

K4는 법령 개정 감지 기능을 형식적으로 시연하는 단계가 아니다. 현재
법령지식베이스와 평가 데이터에 실제 영향을 주는 개정 사례를 공식
원문으로 확인하고, 그 사례를 다음 단계의 버전 비교·영향 분석 입력으로
확정하는 단계다.

## 2. 선정 기준

다음 조건을 모두 충족하는 사례만 채택한다.

1. 국가법령정보센터에서 개정 전 본문, 개정 후 본문, 제정·개정문을
   각각 확인할 수 있다.
2. 현재 41개 지식 항목이 참조하는 조문이 실제로 변경됐다.
3. 기존 지식 항목과 공식 평가 문항이 각각 하나 이상 영향을 받는다.
4. 공포일과 시행일이 명확하다.
5. 자동 생성 신·구법 비교 결과만으로 변경을 확정하지 않는다.

## 3. 채택 사례

| 항목 | 내용 |
|---|---|
| 사례 ID | `pipa-2025-public-safety-basis` |
| 법령 | 개인정보 보호법 (`011357`) |
| 공포 | 2025-04-01, 법률 제20897호 |
| 시행 | 2025-10-02 |
| 변경 조문 | 제15조제1항제7호 |
| 변경 유형 | 호 신설 |
| 개정 후 내용 | 공중위생 등 공공의 안전과 안녕을 위하여 긴급히 필요한 경우 |
| 영향 지식 항목 | `pipa_collection_use` |
| 영향 평가 문항 | `pipa-collection-basis` |

직전 공식 본문에는 제15조제1항이 제6호까지 존재하고, 개정 후 공식
본문에는 제7호가 추가되어 있다. 따라서 개인정보를 동의 없이
수집·이용할 수 있는 법적 근거의 목록을 설명하는 데이터는 개정 전후에
정답 포인트가 달라진다.

## 4. 공식 검증 출처

- [개정 전 개인정보 보호법 본문](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=248613)
- [개정 후 개인정보 보호법 본문](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=270351)
- [법률 제20897호 제정·개정문](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=270351&viewCls=lsRvsDocInfoR)

국가법령정보센터의 신·구법 비교는 자동 생성된 참고자료이므로, 위 세
공식 화면을 대조한 결과를 데이터에 기록했다.

## 5. K4 구현 시 예상 영향

다음 구현에서는 이 사례만 사용하여 범위를 제한한다.

1. 개정 전 제15조와 개정 후 제15조를 별도 버전으로 저장한다.
2. `analyze_legal_kb_update.py`가 제7호 추가를 `added`로 탐지하는지
   확인한다.
3. `pipa_collection_use`를 영향받는 지식 항목으로 추적한다.
4. `pipa-collection-basis`를 재검수 대상 평가 문항으로 추적한다.
5. 개정 전 기준일 질문에는 제7호를 포함하지 않고, 2025-10-02 이후
   질문에는 제7호를 포함하는 시점 평가를 추가한다.

## 6. 본 패치 구현 결과

후보 선정 이후의 실제 비교·영향 추적·시점 평가는
[`K4_AMENDMENT_IMPACT_REPORT.md`](K4_AMENDMENT_IMPACT_REPORT.md)에
기록한다.

## 7. 이번 패치의 범위와 한계

- 실제 개정 사례의 선정과 참조 무결성 검증까지만 수행한다.
- 현행 코퍼스를 과거 버전 데이터로 확장하지 않는다.
- 자동 수집이나 주기 실행을 추가하지 않는다.
- 변경 조문의 법적 의미를 자동으로 판정하지 않는다.
- 다음 패치 전까지 기존 검색·답변 API의 동작은 변하지 않는다.
