# 지원서용 프로젝트 요약

## 공통 3문장

한국 법령의 조·항·호 구조와 시행일을 반영한 근거 기반 RAG QA 시스템을 직접 설계·구현했습니다. 키워드·의미 검색을 결합하고, 생성 답변의 인용 및 문장별 근거를 검증하며, 회귀 평가와 실패 사례를 통해 품질을 관리하도록 구성했습니다. 법률 지식을 단순 검색에 그치지 않고 검증 가능한 데이터·AI 파이프라인으로 전환한 프로젝트입니다.

## 법률 실무 직무용

법률 질문을 쟁점·주체·요건으로 구조화하고 관련 조문과 공식 출처를 함께 제시하는 시스템을 개발했습니다. 근거가 부족하면 답변을 유보하도록 설계해 법률 정보의 신뢰성을 우선했으며, 반복적인 법률 확인 업무를 표준화하는 가능성을 검증했습니다.

## LLM·데이터 품질 직무용

법령 데이터를 조·항·호 단위로 정규화하고 검색용 메타데이터와 평가셋을 설계했습니다. Hybrid Retrieval, Grounding, Citation Validation, Regression Evaluation을 구현해 검색·생성 결과를 정량적으로 검증하고 실패 사례를 추적할 수 있도록 구성했습니다.

## 포트폴리오 링크 설명

공개 법령 데이터를 이용한 비공식 기술 데모입니다. 질문 입력 후 생성 답변, 근거 조문, 공식 출처, 인용 검증 결과를 확인할 수 있습니다.
