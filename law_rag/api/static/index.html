Role Fit
법률 실무와 AI 데이터 품질을 함께 보여주는 프로젝트
같은 시스템을 서로 다른 직무 관점에서 이해할 수 있도록 핵심 역량을 정리했습니다.

    

      

        법률 실무·고객 업무
        
법률 쟁점을 구조화하고 근거를 빠르게 확인합니다.

        
  • 질문에서 법적 행위·주체·요건을 분리
  • 관련 조문과 공식 출처를 함께 제시
  • 근거 부족 시 답변을 유보하는 안전장치
  • 반복적인 법률 확인 업무의 표준화 가능성

      

      

        LLM·데이터 품질
        
학습·검색 데이터와 생성 결과를 평가 가능한 형태로 관리합니다.

        
  • 조·항·호 단위 메타데이터 설계
  • 하이브리드 검색과 검색 순위 평가
  • 문장별 Grounding 및 Citation Validation
  • 회귀 평가와 실패 사례 기반 품질 개선

      

    

    
이 데모는 특정 조직의 내부 시스템을 모사하지 않으며, 공개 법령 데이터만 사용하는 비공식 기술 데모입니다.

Why This Project
법률 도메인에서 필요한 것은 답변 생성보다 검증 가능한 근거입니다.
이 프로젝트는 단순한 챗봇 구현이 아니라, 법령의 구조와 시행 시점을 반영하고 검색 실패·미지원 인용·근거 부족을 명시적으로 관리하는 시스템을 설계하는 데 초점을 두었습니다.
